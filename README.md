# Componente DataRange

Protótipo comparativo de três seletores de intervalo de datas, com edição manual, atalhos de período e votação local para avaliação da interface.

## Executar localmente

```bash
npm start
```

Acesse `http://127.0.0.1:3000/`.

## Observação sobre a votação

Nesta versão, o voto fica salvo no navegador com `localStorage`. Para consolidar votos de pessoas e dispositivos diferentes, será necessário conectar um armazenamento compartilhado.
